# Abartılı Sabah Alarm Makinesi

Bu alarm sizi nazikçe uyandırmaz. Sizi varoluşsal bir nutukla, abartılı bir ciddiyetle yataktan kaldırır. "Uyan! Evren seni bekliyor!" diye bağırır (yazılı olarak).

## Kullanım
```bash
python alarm.py
```
Alarm çalar, siz de kalkarsınız. Ya da kalkmazsınız, o sizin probleminiz.

Sabahlar zor, bu daha zor.
